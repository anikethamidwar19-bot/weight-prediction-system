# ⚖️ Weight Prediction System using Simple Linear Regression

## 📌 Project Overview

This project is a Machine Learning application that predicts a person's weight based on their height using **Simple Linear Regression**.

The model is trained using a dataset containing height and weight values. It learns the relationship between these two variables and predicts weight for a given height.

## 🎯 Project Objective

The main objective of this project is to understand and implement Simple Linear Regression and develop a basic Machine Learning prediction system.

## 🛠️ Technologies Used

- Python
- HTML
- CSS
- JavaScript
- Flask
- Scikit-learn
- Pandas
- NumPy
- Pickle

## 🤖 Machine Learning Algorithm

**Simple Linear Regression**

Simple Linear Regression is a supervised Machine Learning algorithm used to predict a continuous numerical value based on one independent variable.

In this project:
- Independent Variable (X): Height
- Dependent Variable (Y): Weight

## ⚙️ How It Works

1. Collect the height and weight dataset.
2. Load and process the dataset using Python.
3. Train the model using Simple Linear Regression.
4. Save the trained model as a `.pkl` file.
5. Develop a web interface using HTML, CSS, and JavaScript.
6. Use Flask to connect the frontend with the Machine Learning model.
7. Enter a height and get the predicted weight.
